# 文明中国第二阶段实施计划

沿用 Python 数据管线、原生 ES modules 和 Canvas。每步先验证关键数据规则，再接入已有地图入口并复查交互。数据缺口保留为空，公报与年鉴按发布单位和统计口径记录。

1. 在 `pipeline/build/lenses.py` 生成城市和省级统计透镜，接入现有透镜选择器，校验海洋、缺值、跨区和人口年份。
2. 在统计与产出管线补充常住人口和同口径行业就业。验证科目、城乡范围、统计年份与覆盖率。
3. 在统计和设施构建器补充台湾地区合计、港澳台机场与港口。验证币种、单位、地区归属和显示。
4. 在 `web/js/ext/advisors` 接入四个中文顾问。验证排序、缺值、地图定位和移动端浏览。
5. 在年度数据和设施图层接入 2020–2024 年切换。验证稀疏序列、时点及分段开通年份。
6. 在县级扩展和图层菜单接入县区查询、建成区、新区、自贸区。验证地理位置与边界表达。

最后运行 `uv run python -m unittest discover -s tests` 和 `uv run python -m pipeline check`，并检查真实页面。
